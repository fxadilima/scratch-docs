# Scratch Docs

Repository ini dipakai sebagai contoh dokumentasi tanpa menggunakan `jekyll` secara eksplisit, tetapi tetap bisa ditampilkan sebagai `GitHub Pages` tanpa kesulitan.

Semua dokumen yang ingin kita `publish` diletakkan di sebuah folder bernama "docs", dan file bernama "README.md" akan selalu dianggap sebagai "index" bagi semua folder di dalamnya.

Misalnya, ini adalah [link ke Test Page](./test-page.md).
