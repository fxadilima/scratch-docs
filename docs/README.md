
Repository ini dipakai sebagai contoh dokumentasi tanpa menggunakan `jekyll` secara eksplisit, tetapi tetap bisa ditampilkan sebagai `GitHub Pages` tanpa kesulitan.

Semua dokumen yang ingin kita `publish` diletakkan di sebuah folder bernama "docs", dan file bernama "README.md" akan selalu dianggap sebagai "index" bagi semua folder di dalamnya.

Misalnya, ini adalah [link ke Test Page](./test-page.md).

Semua repository kita pasti bisa kita `publish` sebagai WebPages, sepanjang kita sudah [mengaktifkan fitur ini](./mengaktifkan-gh-pages.md) sebelumnya. Secara default, situs kita ini akan bernama seperti "https://fxadilima.github.io" (situs pribadi saya sendiri). Setiap repository kita akan menjadi "sub-folder" dari situs utama tersebut. Misalnya, repository ini bernama "scratch-docs", maka jika repository ini diaktifkan sebagai `GH Pages`, namanya akan menjadi "https://fxadilima.github.io/scratch-docs".

Tanpa melakukan apapun juga (kecuali mengaktifkan GitHub Pages), kita sudah bisa membagikan link kepada teman-teman kita supaya mereka bisa membaca tulisan kita di sini, lengkap dengan segala aksesori di dalamnya, seperti, misalnya, gambar atau video (jika ada). Atau bisa jadi semua link ke YouTube.

Apakah kita harus menulis format rumit yang sulit dibaca seperti HTML?

Jawabnya, "Tidak juga". Atau, tergantung apa keperluan kita selanjutnya. Apa saja yang ingin kita tampilkan di sini, dan bagaimana cara kita menampilkannya. Kita tetap bisa melakukan _styling_ seperlunya, termasuk jika ingin menampilkan `dark mode`, hanya dengan menambahkan beberapa file yang perlu.
